# Entity Exorcist

[English README](README.md)

> Your feeds are haunted. We brought a decoder.

Exorcises malformed HTML entities from RSS article titles.

Расширение исправляет заголовки новых статей в выбранных лентах. Исправленный заголовок сохраняется в базе и используется веб-интерфейсом и API FreshRSS.

## Установка

Понадобятся FreshRSS **1.29.0 или новее**, PHP **8.1 или новее** и Git. Проверены FreshRSS 1.29.0 и 1.30.4.

Перейдите в каталог `extensions/` вашей установки FreshRSS и клонируйте репозиторий.

```sh
cd /path/to/FreshRSS/extensions
git clone https://github.com/konkere/xExtension-EntityExorcist.git
```

Если в вашей установке задан `THIRDPARTY_EXTENSIONS_PATH`, выполните `git clone` в указанном каталоге. Если каталог расширений Docker проброшен с хоста, клонируйте репозиторий в соответствующий каталог на хосте. Файл `metadata.json` должен оказаться непосредственно в новом каталоге `xExtension-EntityExorcist/`. [Руководство FreshRSS по установке расширений](https://freshrss.github.io/FreshRSS/en/admins/15_extensions.html#how-to-install)

Чтобы обновить расширение, установленное через Git, выполните `git -C xExtension-EntityExorcist pull --ff-only` из того же каталога расширений.

## Настройка

1. Откройте **Настройки → Расширения**, включите **Entity Exorcist** и откройте его настройки.
2. В **Feeds to repair** раскройте нужные категории FreshRSS, отметьте подписки и сохраните. Рядом с названием категории указано число её лент. Категории с ранее отмеченными подписками открываются автоматически. Настройки индивидуальны для каждого пользователя FreshRSS. Снимите все отметки и сохраните, чтобы остановить обработку.

В списке показаны реальные подписки с их ID. При обычном удалении и повторном добавлении лента получает новый ID и требует повторного выбора. При сохранении удалённые ID отбрасываются. После восстановления базы с другими ID перепроверьте выбор.

Параметр **Replace non-breaking spaces with regular spaces in selected feeds** по умолчанию выключен. Тогда `&nbsp;`, `&#160;` и `&#xA0;` декодируются в неразрывный пробел U+00A0. С включённым параметром все U+00A0 в новых заголовках выбранных лент заменяются обычным пробелом. FreshRSS убирает обычные пробелы по краям заголовка при сохранении.

## Что меняется

Расширение снимает служебное экранирование текста FreshRSS, один раз пропускает полученный заголовок через PHP `html_entity_decode` с `ENT_HTML5` и снова безопасно экранирует результат перед записью. Неизвестные и неполные записи вроде `&unknown;` и `&quot` сохраняются. Если после преобразования заголовок пуст, содержит управляющие символы или становится равен GUID, расширение оставляет исходный заголовок. В выбранной ленте осознанно напечатанная валидная сущность вроде `&copy;` тоже будет декодирована.

Примеры показывают текст заголовка после XML-разбора и после исправления.

| После XML-разбора | После исправления |
| --- | --- |
| `&quot;Сантафобия&quot;` | `"Сантафобия"` |
| `Black Lake &#45; Official Story Trailer` | `Black Lake - Official Story Trailer` |
| `Rock &amp; Roll` | `Rock & Roll` |
| `&#x1F600; &NotEqualTilde;` | `😀 ≂̸` |
| `&amp;quot;Цитата&amp;quot;` | `&quot;Цитата&quot;` |
| `R&D — обычный заголовок` | `R&D — обычный заголовок` |

Например, `<title>&quot;Цитата&quot;</title>` уже даёт корректные кавычки при XML-разборе. В `<title><![CDATA[&quot;Цитата&quot;]]></title>` последовательность сохраняется буквально и подлежит исправлению. Двойное кодирование оставляет один слой. Угловые скобки из сущностей отображаются как текст.

Хук `EntryBeforeAdd` вызывается перед сохранением новой статьи, в том числе при импорте новых записей. В FreshRSS `EntryBeforeInsert` также вызывается для обновлений, поэтому расширение использует хук добавления. Исправление не меняет ранее сохранённые статьи, тело, ссылку, GUID и исходный хеш статьи. Штатные фильтры FreshRSS при обновлении ленты выполняются раньше исправления и видят исходный заголовок. [Документация хуков](https://freshrss.github.io/FreshRSS/en/developers/03_Backend/05_Extensions.html) · [Код обновления лент в 1.30.4](https://github.com/FreshRSS/FreshRSS/blob/1.30.4/app/Controllers/feedController.php).

## Проверка на тестовой установке

### Живая лента без ожидания новых публикаций

На FreshRSS 1.30.4 импортируйте [horrorzone-live.opml](tests/horrorzone-live.opml) через **Управление подписками → Импорт / экспорт**. Файл использует исходный URL `https://horrorzone.ru/feed`. Если HorrorZone уже есть в этом аккаунте, выполните тест в отдельном аккаунте тестового FreshRSS, поскольку импорт того же URL повторно использует существующую подписку.

Новая подписка **HorrorZone — Entity Exorcist test** создаётся с выключенным автообновлением. Отметьте её в настройках Entity Exorcist и нажмите **Обновить ленту** в настройках этой подписки. В неё загрузятся статьи, которые HorrorZone отдаёт сейчас. После проверки тестовую подписку можно удалить.

Кнопка **Перезагрузить статьи** перечитывает источник, но FreshRSS по-прежнему распознаёт существующие записи по GUID. Для исправления при добавлении нужен новый импорт в пустую подписку. [Код перезагрузки в FreshRSS 1.30.4](https://github.com/FreshRSS/FreshRSS/blob/1.30.4/app/Controllers/feedController.php#L1230).

### Обычная подписка и воспроизводимый образец

1. Добавьте [HorrorZone](https://horrorzone.ru/feed) и отметьте её в настройках расширения. Первичная загрузка при добавлении ленты может закончиться раньше, чем появится возможность её выбрать.
2. Дождитесь новой статьи с буквальными сущностями и обновите ленту. Сверьте заголовок в веб-интерфейсе и в Android-клиенте после синхронизации. Проверьте, что прежде сохранённая статья и статьи в другой, невыбранной ленте не изменились.
3. Для воспроизводимой проверки можно использовать [RSS-образец](tests/fixture.xml) по URL, уже доступному вашей тестовой установке. Начните с ленты без элементов `item`. Подпишитесь, включите обработку для этой ленты, затем добавьте элементы из образца по тому же URL и обновите подписку. Чтобы повторить проверку, задайте образцам новые GUID. Ожидаемые заголовки указаны в таблице.

Google Reader API в режиме совместимости FreshRSS и Fever могут выводить `＆`, `＜` и `＞` вместо ASCII-символов. Это штатное форматирование этих API. Кавычки и дефис в двух примерах HorrorZone проверяются без таких замен. [Сериализация Google Reader в FreshRSS](https://github.com/FreshRSS/FreshRSS/blob/1.30.4/app/Models/Entry.php).

## Локальные проверки без сервера

Запускайте из каталога расширения с чистой распакованной копией исходников FreshRSS. Нужен PHP CLI с модулями FreshRSS, включая DOM/XML, cURL, mbstring и PDO SQLite.

```sh
php -l extension.php
php -l configure.phtml
php -l tests/run.php
php tests/run.php /path/to/FreshRSS-1.30.4
```

Проверка использует реальный загрузчик расширений, форму и сохранение настроек, SimplePie, временную SQLite и сериализацию Google Reader API. Тестовые данные размещаются во временном каталоге и удаляются в конце. HTTP-сервер для этой проверки не нужен.
